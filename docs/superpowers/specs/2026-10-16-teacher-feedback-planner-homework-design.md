# 老師使用回饋（2026-10-16）：課程規劃表與作業小管家調整

- 日期：2026-10-16
- 狀態：設計已確認，待撰寫實作計畫
- 依據：老師上線一週後的使用心得；主設計文件 `2026-10-07-mumu-class-workbench-design.md`（以下稱「主文件」）§5.5、§5.6、§8.1、§8.4

## 1. 老師的回饋

**課程規劃表**
1. 格子太寬，左邊固定欄佔太多空間，看不到整體。
2. 刪掉「備註」欄、「堂」欄。
3. 「其他」分組：其他科目拆成數學、自然、其他三欄；另加「其他考試」一欄（共用），一樣提前一個上學日預告。
4. 作業格的內容改為靠左、靠上對齊。
5. 作業總覽拆成「作業」與「訂簽」兩塊分別彙整，其他分組裡的作業和訂簽也要整理進來。
6. 作業格要可以換行。

**作業小管家**
1. 進行中的作業可以調換順序。
2. 可以看同一個學生的個人缺交清單。

## 2. 決策紀錄

| # | 問題 | 決定 |
|---|---|---|
| D1 | 欄位異動怎麼套用到已在使用的資料庫 | 寫 SQL migration，不在前端比對補欄 |
| D2 | 左側固定欄 | 電腦固定週次、日期、作業總覽；手機只固定一個「週｜日期」窄欄 |
| D3 | 堂、備註的舊資料 | 只從畫面與 CSV 隱藏，資料庫保留 |
| D4 | 作業總覽怎麼拆 | 同一格內上下兩塊：上面作業、下面訂簽 |
| D5 | 換行操作 | 自動折行；Alt／Option＋Enter 或 Shift＋Enter 手動換行；Enter 仍跳到下一個上學日 |
| D6 | 其他考試的推算 | 每個項目都在前一個上學日預告，不看有沒有數字；考試當天不另外顯示 |

## 3. 資料庫異動（一個 migration）

檔名：`supabase/migrations/20261016120000_teacher_feedback.sql`。正式環境有兩個帳號（老師、維護者的測試帳號），每個帳號各有一組 `planner_columns`，migration 要對**每一個 owner** 都套用。

### 3.1 `planner_columns`
- 新增欄位 `hidden boolean not null default false`。
- 把 `key in ('堂', '備註')` 的欄設為 `hidden = true`。這兩欄的 `planner_entries` 不刪除。
- 每個已有欄位的 owner，若還沒有下列欄位就新增（`group_name = '其他'`、`in_summary = true`、`item_id = null`）：

| key | label | kind |
|---|---|---|
| 數學 | 數學 | text |
| 自然 | 自然 | text |
| 其他考試 | 其他考試 | multiline |

- 重排「其他」分組的 `sort_order`：設為該 owner 非「其他」分組欄位的最大 `sort_order` 之後的連續數字，順序為數學、自然、其他、其他考試、（隱藏的）備註。其他分組的欄位不動。原有「其他」欄的 key 不變，已填內容留在原處。
- 第 4 節說明 `kind` 不再影響畫面上的編輯方式；保留 `text`／`multiline` 只為了相容既有資料。

### 3.2 `homework_assignments`
- 新增欄位 `sort_order int not null default 0`。

### 3.3 新班級的預設值
`src/lib/defaults.ts` 的 `DEFAULT_PLANNER_COLUMNS` 同步改成新的欄位組合：
- 拿掉「堂」「備註」，新班級不會有這兩欄；
- 「其他」分組改為數學、自然、其他、其他考試；其他考試為 `multiline`。

`PlannerColumn` 型別加上 `hidden: boolean`。

## 4. 課程規劃表

### 4.1 版面與固定欄（回饋 1、2）

| 寬度 | 固定欄 | 可捲動的欄 |
|---|---|---|
| ≥ 768px（Tailwind `md`） | 週次（40px）、日期（56px）、作業總覽（約 220px），合計約 316px | 重要行事曆（140px）、課堂進度（180px）、所有作業欄 |
| < 768px | 一個「週｜日期」欄（約 52px），週次欄隱藏，週次顯示在日期格內 | 作業總覽、重要行事曆、課堂進度、所有作業欄 |

- 作業欄最小寬度 92px 改成 72px。原本放寬到 120px 的欄（寫作、字詞考、國單元考、社單元考、其他）改成 100px，「其他考試」也放寬到 100px。
- 固定欄的 `left` 位移改用 `md:` 前綴，手機上不套用。
- `hidden = true` 的欄位不出現在表頭、表身、CSV。「堂」欄（`kind = 'period'`）的渲染程式碼一併移除。
- 主文件 §8.4「左側 6 欄固定」由本節取代。
- 追加（2026-10-17）：電腦版全站左側選單可收合成只剩圖示的窄欄（約 64px），狀態記在該裝置瀏覽器的 localStorage（`mumu.sidebar`）；課程規劃頁不受內容最大寬度 1152px 限制，其他頁面維持。實作在 `src/app/Layout.tsx`。

### 4.2 作業格：對齊與換行（回饋 4、6）

- 所有作業欄一律用自動長高的文字框（現有的 `AutoTextarea`），靠左、靠上對齊，長字自動折行。不再依 `kind` 區分單行輸入框和多行文字框。
- 按鍵：
  - **Enter**：跳到下一個上學日的同一欄（沿用現有的 `moveDown`，改成支援文字框）。
  - **Alt／Option＋Enter**、**Shift＋Enter**：在格子內換行。
- 原本的多行欄（字詞考、國單元考、社單元考）以前按 Enter 是換行，現在也改成跳下一列，所有欄位操作一致。
- 中文輸入法選字時按 Enter（`isComposing` 為真）不觸發跳列。

### 4.3 推算規則調整

主文件 §8.4 的規則表做以下修改。

**一律以項目為單位判斷。** 所有作業欄都用 `splitEntries` 拆成項目（以換行、`；`、`;` 分隔），每個項目分別套用規則。以前只有多行欄這樣做。影響：
- R1（國課練、字詞本）：例如國課練填「L3」換行「訂簽」，「L3」帶入國語課程進度，「訂簽」列入訂簽總覽。
- R6（其他作業欄）：每個項目各成一筆「{欄名}｜{項目}」。

**新增 R8 其他考試。** 每個項目（不看有沒有數字、有沒有訂簽）都在**前一個上學日**的作業總覽「作業」塊加上「週{X}考{項目}」，X 為考試當天的星期。例：週三填「數L3」，週二的作業總覽出現「週三考數L3」。考試當天不在作業總覽或課堂進度另外顯示。

**數學、自然、其他** 這三欄沒有特殊規則，套用 R6。

### 4.4 作業總覽拆成「作業」與「訂簽」（回饋 5）

- 分類規則：項目內容包含「訂簽」兩個字 → 訂簽塊；其他所有項目、以及所有考試預告（R3、R4、R5、R8）→ 作業塊。
- `summaryItems` 的回傳改成 `{ homework: SummaryItem[]; sign: SummaryItem[] }`。
- 格子內的版面比照「課堂進度」：左側小標「作業」「訂簽」，上下兩塊以細線分隔，空的一塊顯示「—」。
- 包含「其他」分組的數學、自然、其他三欄。
- CSV：原「當日作業總覽」一欄改成「作業總覽」「訂簽總覽」兩欄；「堂」欄移除。

## 5. 作業小管家

### 5.1 進行中作業的排序（回饋 1）

- 進行中作業的排序：先依 `sort_order` 由小到大，相同時依現行順序（`assigned_date` 新到舊、`created_at` 新到舊）。
- 新建立的作業 `sort_order = 0`，排在最前面，維持現行行為。
- 「今日作業」分頁裡，**目前選中**的作業標籤兩側出現 ◀ ▶ 按鈕（最前面沒有 ◀，最後面沒有 ▶）。每按一次和相鄰的作業交換位置，並把所有進行中作業的 `sort_order` 依新順序重新編為 1、2、3…（從 1 開始，之後新建的作業 0 一定排在最前面）。
- 樂觀更新：先改畫面，寫入失敗時還原並顯示提示（比照 `useSetChecks`）。
- 「缺交總覽」的作業標籤使用同一個順序。

### 5.2 依學生檢視缺交（回饋 2）

- 「缺交總覽」頂端加「依作業｜依學生」切換，預設依作業（現行畫面）。
- **依學生**：只列出在任一份進行中作業有缺交的學生，依座號排序。每位學生一張卡片：
  - 第一行大字：座號、姓名、「缺 N」；
  - 下面依 5.1 的作業順序列出缺交的作業標題（`itemTitle`）。
- 字級比照現行缺交卡片，方便投影給全班看。
- 沒有任何缺交時顯示「✓ 全班完成」；沒有進行中作業時顯示現有的空狀態文字。
- 已封存的作業不列入（封存紀錄已在「學生歷程」）。
